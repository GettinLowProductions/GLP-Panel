Stay in control without the hassle

Getting a server running is only half the job. Keeping it running smoothly matters just as much.

GLP Server Panel gives you the tools to manage your servers without constantly digging through folders or switching between applications.

  • Live console: See what's happening on your server and send commands directly.
  • Player management: View connected players, kick players, and send announcements through supported RCON systems.
  • Performance controls: Monitor resource usage and set CPU and memory limits for individual servers.
  • Automatic restarts: Schedule restarts around your players instead of remembering to do them yourself.
  • Crash detection: Know when something goes wrong, with optional Discord notifications.
  • Backups and recovery: Back up your server data and restore it when needed.
  • File management: Browse files and edit configurations directly, with built-in checks for JSON and XML.

Whether you're running one small server for friends or several different worlds, everything is accessible from the same panel.

More than one computer? No problem.

Maybe you've got an old PC sitting around. Maybe a friend wants to contribute some hardware. Or perhaps you've rented a VPS and want to manage it alongside your home servers.

GLP Server Panel lets you bring those machines together.

When you launch the panel for the first time, you can choose to host locally, join a friend's setup, or connect to an existing panel.

From there, you can manage connected machines and decide exactly what other people are allowed to access.

Give a trusted friend administrative control, let someone manage only a particular server, or provide view-only access.

There's even built-in team chat with support for sharing files and GIFs.

For remote connections, you can use Tailscale or direct HTTPS, with security features including login rate limiting and activity logs.

Getting your friends connected shouldn't be complicated

Port forwarding, firewall rules, IP addresses... if you've never hosted a server before, networking can be one of the most frustrating parts.

We wanted to make that easier.

The Go Live checklist helps you work through the process, including Windows Firewall permissions, router configuration, and setting up a free DuckDNS address.

Where supported, the panel can configure port forwarding automatically. If your router needs manual setup, we'll help guide you through it.

Can't port forward? You still have options.

GLP Server Panel also supports sharing through playit, giving you another way to make your server accessible.

You'll be guided through any required account approval, and once your public address is ready, you can copy it and share it with your friends.

The goal is simple: less troubleshooting, more playing.

Need a hand? We've got you.

Not everyone is a network engineer, and you shouldn't need to be one to host a game server.

Our built-in Help & FAQ section explains common setup problems, networking questions, and the things you should know before making changes.

Stuck on something? Ask Miles, the panel's built-in Ask Tech helper. He runs right on your PC and can walk you through setup and common problems in plain English, without ever leaving the panel.

And if something isn't working the way it should, you can send a bug report directly from the panel.

Tell us what happened, and the panel can include relevant diagnostic information to help us investigate. Sensitive information such as passwords, tokens, and network addresses is filtered locally before the report is sent.

If the report can't be delivered, we'll tell you rather than leaving you wondering.

Update the panel, not your whole setup

Nobody wants to lose a carefully built world because they updated an application.

GLP Server Panel is designed to keep your existing servers, worlds, settings, and sign-in information intact when you install an update.

Your worlds belong to you. Updating the software shouldn't mean starting over.
