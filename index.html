What it is

One installer on your PC

The panel sets up what each game needs: the right Java version, SteamCMD, server files, and Workshop mods with their dependencies and signing keys. A Go Live checklist covers the firewall, the router, and a free stable address so friends can join.

It is free and self-hosted. Your hardware, your servers, your data. Windows only.

Games

What you can host

Minecraft Java

One-click Fabric. Search mods in the panel on Modrinth and CurseForge. Dependencies are resolved, and files are checked with SHA-1.

DayZ / Arma 3

Search the Workshop in the panel, or paste a link. Required items are pulled in. Keys and load order are handled.

Other games

Start from a generic SteamCMD template, or write your own JSON template.

Running servers

While a server is up

  • Live console with commands.
  • RCON player list, kick, and broadcast for BattlEye and Minecraft.
  • RAM and CPU caps for each server, plus live stats.
  • Scheduled restarts.
  • Crash detection, with a Discord notification.
  • Backups and restore.
  • File manager, and config editors that check JSON and XML.

Playing with friends

More than one PC

A friend's PC, or a rented VPS, joins as a node with the setup wizard. First launch asks one question: host here, join a friend's panel, or connect to a panel that already exists.

You set each person's access, from full admin to view-only, per server and per capability. Team chat can share files and GIFs. Remote access is through Tailscale (recommended) or direct HTTPS, with login rate limiting and an audit log.

Beginner help

Help, Go Live, and sharing

Help & FAQ walks through firewalls, routers, port forwarding, and what is safe to click. The Go Live checklist does the hard parts: a firewall rule after one prompt, UPnP port forwarding with a manual fallback, a free DuckDNS address, and an invite friends can copy.

Share without port forwarding

After you approve the link, the panel leaves the waiting message and shows what is actually going on. If playit still needs you to confirm the email on that account, that message stays until you do. When a public address is ready, it is shown with a copy button.

Sharing uses the same ports Go Live lists, including extra ports a game opens beside its main one. That works while the server is stopped. Turning sharing on for another server uses the link you already approved.

Bug reports

Help includes a bug report page. Write what happened, then press Send bug report. The note can be long. Recent logs from this PC and the list of servers are included. Passwords, tokens, and network addresses are removed on this PC before the report goes out. If it cannot be sent, the panel says so.

You can also open an issue on the project.

Updates

Your worlds stay put

The installer adds shortcuts, firewall pre-authorization, and the WebView2 runtime. Upgrades do not touch your server data. Settings, servers, worlds, and sign-in are kept when you update.
